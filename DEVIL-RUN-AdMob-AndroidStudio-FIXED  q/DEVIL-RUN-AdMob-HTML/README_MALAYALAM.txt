DEVIL RUN + ADMOB (Android Studio project)

Ee project-il ningal ayacha HTML game undu. Death aakumbol GAME OVER panel-il WATCH AD TO REVIVE, RESTART LEVEL buttons varum. Android app-il Google Mobile Ads SDK rewarded ad integration add cheythittundu.

IMPORTANT:
1) ZIP extract cheyyuka.
2) Android Studio install/open cheythu File > Open vazhi DEVIL-RUN-AdMob folder select cheyyuka.
3) Gradle sync complete aakunnath vare wait cheyyuka. Android SDK Platform 35 install cheyyan chodichaal install cheyyuka.
4) First testing-inu Google test Rewarded Ad Unit ID use cheyyuka. File: app/src/main/java/com/devilrun/game/MainActivity.kt; REWARDED_AD_UNIT_ID constant maatti test ID aakkuka: ca-app-pub-3940256099942544/5224354917
5) App ID manifest-il ningalude ID aayi set cheythittundu. Test kazhinju ningalude rewarded ID veendum use cheyyuka.
6) Run button amarthi Android phone/emulator-il test cheyyuka. Internet venam.

Note: Ee source project aanu, ready-made APK alla. Ee environment-il Android SDK use cheythu build/test cheythittilla. Actual ad availability, AdMob account approval, app configuration enniva Google side-il depend cheyyum. Production-il publish cheyyunnathinu munpu Google AdMob policies follow cheyyuka; ads-ne click cheyyan user-ne encourage cheyyaruthu.
